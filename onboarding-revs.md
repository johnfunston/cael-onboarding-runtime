Module Structure
Module 1 — Foundations

Intention:
Explain what CAEL is, why it exists, and the core design insight: aligning software architecture with cognitive architecture.

Concepts in scope:
• Why knowledge structure matters
• Why cognitive functions were abstracted
• Archetypes as named cognitive service roles
• Mapping cognitive roles → computational services
• Why this mapping improves usability
• The cognitive feedback loop created by using the system

.rev documents in this module:

1 genesis.rev — Why linear knowledge tools hide reasoning structure

2 cognitive.abstraction.rev — Why cognitive functions were abstracted into archetypal labels

3 cognitive.to.computational.mapping.rev — How cognitive roles map to software services

4 architecture.why.it.matters.rev — Why architecture aligned to cognition improves usability

5 cognitive.feedback.loop.rev — How using the system reflects cognition back to the user

These five .revs already exist and serve as tone references.
